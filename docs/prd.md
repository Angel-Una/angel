# 需求文档

## 1. 应用概述

### 1.1 应用名称
微信风格 AI 智能聊天系统

### 1.2 应用描述
一款基于 Web 端的多会话 AI 聊天应用。界面高度还原微信即时通讯交互与视觉风格，支持多联系人会话管理、群聊创建、自定义气泡美化与聊天背景图。系统支持配置第三方 AI 文本与语音 API、基础运行参数（如上下文上限），单聊支持导入人设与世界观设定；支持消息时间戳展示、长按重新编辑与多版本重新生成；提供后台消息通知与后台保活运行能力。

## 2. 用户与使用场景

### 2.1 目标用户
需要通过微信即时通讯风格界面与自定义 AI 角色或群聊进行文本与语音互动，具备快速配置常见厂商 API 密钥、角色人设与世界观导入、上下文参数调节、后台运行保活及个性化视觉定制需求的用户。

### 2.2 核心使用场景
- **联系人与群聊管理**：用户在「联系人」页查看多会话列表，添加新联系人或创建群聊；在聊天设置中修改头像与名称，或删除联系人/解散群聊。
- **单聊人设与世界观配置**：在单聊设置中导入角色人设与世界观内容作为对话前提。
- **消息交互与多版本生成**：在聊天页输入栏左侧点击加号发送图片，或输入文本发送消息；查看消息时间戳；长按消息可重新编辑或触发重新生成，重新生成后可在多版本间左右切换查看。
- **后台通知与保活**：在「我的」页开启后台通知与后台保活，在页面置于后台时持续运行并接收系统通知。
- **快速 API 配置**：在「我的」页通过选择商家快速填充接口地址并选择模型，仅需填写 API Key 即可完成文本 API 配置。

### 3.2 功能说明

#### 3.2.1 底部导航栏
- 提供「联系人」与「我的」两个主导航 Tab，支持快速切换。

#### 3.2.2 联系人页面（首页）
- **顶部操作栏**：加号菜单支持添加联系人（上传头像、输入昵称）与创建群聊（上传群头像、输入群名称、勾选联系人成员）。
- **会话列表展示**：展示头像、昵称/群名、最新一条消息摘要及时间，点击进入聊天页面。

#### 3.2.3 聊天页面
- **顶部导航栏**：左侧返回按钮，中间展示名称，右上角三点菜单呼出设置弹窗（单聊支持修改资料、导入人设、世界观配置、气泡 CSS、背景图与删除；群聊支持修改资料、气泡 CSS、背景图与解散）。
- **聊天消息展示区**：
  - 消息展示：采用微信风格布局与气泡样式，展示发送/接收时间戳，支持纯文本、图片预览与语音播放及转文字。
  - **多版本消息展示**：当某条 AI 回复经历多次重新生成时，消息气泡上方或下方展示版本指示器（格式如「1/2」），提供左右切换箭头，支持在历史版本与最新版本间切换显示。
  - **消息长按悬浮菜单**：长按双方消息弹出菜单：
    - **重新编辑**：编辑修改当前消息文本内容并保存。
    - **重新生成**：请求 AI 生成新的回复内容，保留旧版本并新增版本索引。
- **底部输入工具栏**：
  - **加号（发送图片）按钮**：固定位于底部输入栏**最左侧**，点击唤起图片选择与发送。
  - **输入与发送**：右侧提供文本输入框与发送操作。

#### 3.2.4 我的页面
- **我的头像管理**：支持上传、更换与保存个人头像。
- **基础设置**：配置对话携带的上下文上限条数/长度。
- **后台运行模块**：
  - **后台消息通知**：开关控制。开启时请求浏览器系统通知权限；当页面处于后台/隐藏状态且收到新消息时弹出系统通知。开启该项时自动联动开启「后台保活」。
  - **后台保活**：开关控制。开启后通过静音音频循环播放及屏幕唤醒锁（Wake Lock）防止页面被系统休眠挂起；界面实时显示当前保活运行时长。
- **文本 API 配置模块**：
  - **商家选择模式**：提供常见 API 商家下拉列表（包含 DeepSeek、Google Gemini、OpenAI、通义千问、智谱清言、Moonshot Kimi、MiniMax、OpenRouter 等）。
  - **参数自动填充**：选择商家后，自动填充对应商家的 API 请求地址，并联动加载该商家支持的模型列表供下拉选择。
  - **密钥与范围**：用户输入对应的 API Key，并指定生效范围（全局 / 指定联系人）。
- **语音 API 配置模块**：配置 TTS 与 ASR 接口地址、API Key、模型参数及作用范围。

## 4. 业务规则与核心逻辑

1. **API 商家联动规则**：切换文本 API 商家时，系统自动更新默认的 Base URL 与模型下拉选项列表；用户保存配置时一并持久化所选商家、地址、模型及 API Key。
2. **多版本重新生成规则**：
   - 对 AI 回复消息触发「重新生成」时，系统保留原有回复内容作为历史版本，将新生成的回复追加至版本列表末尾。
   - 消息版本指示按「当前查看索引/总版本数」展示（如 1/3、2/3），切换版本仅改变当前展示的内容，不删除其他历史版本数据。
3. **后台通知与保活联动规则**：
   - 用户手动开启「后台消息通知」时，系统强制将「后台保活」状态同步置为开启。
   - 用户单独关闭「后台保活」时，后台消息通知自动同步关闭；单独关闭「后台消息通知」时，后台保活可保持独立开启。
   - 保活开启后开始统计并展示持续运行时长，关闭后重置时长。
4. **时间戳展示规则**：所有发送及接收的消息均记录并展示对应的发送时间戳。
5. **人设与世界观隔离规则**：导入的人设与世界观仅在单聊会话中生效，群聊中不继承且不展示相关配置。
6. **数据持久化规则**：联系人、群聊关系、消息记录（含多版本回复与时间戳）、人设世界观配置、基础参数、后台设置状态及 API 配置均由后端持久化存储。

## 5. 异常与边界情况

| 序号 | 异常/边界场景 | 表现与处理逻辑 |
| :--- | :--- | :--- |
| 1 | 用户拒绝浏览器系统通知权限 | 提示权限获取失败，保持后台通知开关为关闭状态 |
| 2 | 浏览器不支持 Wake Lock API | 降级仅使用静音音频循环方案维持后台运行，不阻断保活功能开启 |
| 3 | 某条消息处于版本 1/1 时 | 版本指示器隐藏或左右切换箭头置灰不可点击 |
| 4 | 切换 API 商家后未填写 API Key 即保存 | 提示 API Key 不能为空，阻止保存 |
| 5 | 导入的人设文件内容为空或解析失败 | 提示文件解析失败，保持原有设定不变 |

## 6. 验收标准

1. 添加文本 API 配置时可从商家列表中选择（如 DeepSeek、OpenAI 等），API 地址自动填入且模型列表支持下拉选择，输入 Key 后可成功调用。
2. 聊天页面底部输入栏的加号（发图）按钮位于输入框最左侧，点击可正常选择并发送图片。
3. 聊天消息列表正常展示每条消息的时间戳。
4. 对 AI 消息执行重新生成后，生成多版本内容，展示「1/2」等版本指示，点击左右箭头可平滑切换查看不同版本的回复内容。
5. 在「我的」页开启后台通知时可自动联动开启后台保活，页面隐藏且收到新消息时触发浏览器系统通知，且保活运行时长正常计时展示。
6. 单聊人设与世界观导入、上下文上限配置及联系人/群聊管理等原有核心功能运行正常。
